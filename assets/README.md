# Recursos multimedia

Esta carpeta contiene los recursos utilizados por las páginas del CV.

## Estructura

```text
assets/
├── images/
│   ├── foto-perfil.jpeg
│   └── sistema-finanzas.png
├── audio/
│   └── presentacion.mp3
└── video/
    ├── proyecto.mp4
    └── proyecto.mkv
```

## Imágenes

- `foto-perfil.jpeg`: fotografía utilizada en el encabezado de `index.html`.
- `sistema-finanzas.png`: imagen de evidencia del proyecto Sistema de Finanzas.

Todas las imágenes utilizadas en el contenido deben incluir un atributo `alt` descriptivo.

## Audio

- `presentacion.mp3`: presentación personal reproducida en `multimedia.html`.

El archivo se carga mediante el elemento HTML5 `<audio>`.

## Video

- `proyecto.mp4`: video utilizado por el navegador mediante el elemento `<video>`.
- `proyecto.mkv`: archivo original conservado como respaldo.

El formato recomendado para publicar el proyecto es MP4 porque ofrece mayor compatibilidad con los navegadores.
